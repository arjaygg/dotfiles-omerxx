# BMAD Custom PR Review (shim → `lensed-review`)

This skill holds **no review logic**. Retirement record: `ai/skills/REMOVALS.md`.

## Forward

Keep the detection phase (forge detection, Charcoal stack layering, incremental-diff scoping) —
that is plumbing. For each layer, invoke `lensed-review` with lenses `correctness`, `security`,
`resilience`, `style`, and `doubt` (the adversarial pass BMAD's name refers to), scoped to that
layer's incremental diff only.

## Legacy output contract (pinned)

Per-layer comment, posted with `az repos pr thread create --id <PR_ID> --comment "<findings>"
--organization "https://dev.azure.com/bofaz" --project "Axos-Universal-Core"` on Azure DevOps, or
`gh pr review <PR_NUMBER> --comment --body "<findings>"` on GitHub:

```markdown
## BMAD Adversarial Review — Layer N of M

**Branch:** `<branch>` → `<parent_branch>`
**Scope:** Incremental diff only (N files, +X/-Y lines)

### Findings

[findings here]

---
*Generated by bmad-custom-pr-review (stack-aware mode)*
```

- No open PR for a branch: print `No open PR found for branch <branch> — skipping comment post`
  and continue; never fail the run.
- Terminal summary table: `Layer | Branch | PR# | Findings | Posted`.
